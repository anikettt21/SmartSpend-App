SpendSmart is a **beautiful, fully offline** personal expense tracker for Android with a **premium dark glassmorphic UI**. Track spending, set budgets, split group expenses, manage subscriptions, and stay on top of your finances — all without your data ever leaving your phone.

> **🔒 Privacy First** — Zero network permissions. No accounts. No ads. No tracking. Your financial data stays on your device, always.

---

## ✨ Features

### 📊 Financial Health Dashboard
- At-a-glance view of **total spent**, **daily average**, and **total income**
- **Budget progress bar** with remaining amount and percentage tracking
- **Recent activity** feed with your latest transactions

### 💰 Budget Management
- Set a **monthly spending budget** and track progress visually
- Set **per-category budgets** to control spending in specific areas
- Get warnings when you're approaching or exceeding your budget

### 📂 Smart Categories
- Pre-built default categories with icons
- **Create custom categories** with emoji icons
- Categorize every transaction for clear spending breakdowns

### 🏦 Multi-Account Tracking
- Track spending across **Cash, UPI, and multiple bank accounts**
- Add and manage bank accounts from Settings
- See which payment method was used for each transaction

### 📈 Analysis & Reports
- **Category-wise breakdown** with progress bars showing spending distribution
- **Calendar Heatmap** — visualize your spending intensity day-by-day (GitHub contribution graph style 🔥)
- **Spending streaks** — track consecutive days under budget
- Monthly **income vs. expense vs. net balance** summary
- Navigate between months to compare spending patterns

### 👥 Group Expenses
- Create groups to **split expenses** with friends and family
- Track shared costs for trips, roommates, dinners, etc.
- View **member balances** to see who owes what
- Lightweight Splitwise alternative, fully offline

### 🔄 Recurring Subscriptions
- Auto-log recurring expenses (Netflix, Spotify, rent, EMIs, etc.)
- Set the **day of month** for automatic entries
- Assign category and payment account per subscription
- Supports both recurring expenses and income

### ✅ Task Reminders
- Built-in **to-do / reminder system** for financial tasks
- **Persistent notifications** that stay until you act on them
- Filter by: All, Overdue, Today, or Completed
- Swipe actions for quick task management

### 📤 Export & Backup
- **Export to CSV** — download your full transaction history anytime
- Use with Excel, Google Sheets, or any spreadsheet tool

### 📱 Home Screen Widget
- Quick-glance **balance widget** for your home screen
- See your financial status without opening the app

### 🔔 Smart Notifications
- **Daily Spending Summary** — end-of-day recap
- **Budget Alerts** — warnings when approaching limits
- **Bill Reminders** — never miss a payment
- **Weekly Report** — weekly spending overview
- **Logging Reminders** — gentle nudges to keep tracking

### 🎨 Premium Dark UI
- **Glassmorphic card design** with depth and translucency
- Cyan & purple accent palette on deep navy backgrounds
- Smooth animations and transitions
- Material Design 3 components throughout

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Language | Kotlin |
| Architecture | MVVM (ViewModel + LiveData) |
| Database | Room (SQLite) |
| UI | Material Design 3 + ViewBinding |
| Navigation | Jetpack Navigation Component |
| Background | WorkManager |
| Min SDK | Android 7.0 (API 24) |
